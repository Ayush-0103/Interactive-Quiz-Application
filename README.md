This is the file for Interactive Quiz Application which contains frontend interface of the app made using React js.

This Application Includes features like:
- Quiz questions and answers
- Allow users to select one of the options as their answer for the
 current question
- Keep track of the user's current question number and the total
 number of questions
- When the user submits their answer (e.g., by clicking a "Next"
 button) it compare their selection with the correct answer
- Provide immediate feedback to the user after they submit an
 answer
- Include a button to allow users to restart the quiz
- "Recent Results" where you can view your recent scores and can track your progress
